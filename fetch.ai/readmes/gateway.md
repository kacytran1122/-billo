# Billo iMessage Gateway (helper)

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

A thin adapter that connects Billo's iMessage line (Photon Spectrum) to the Billo Coordinator, so iMessage and ASI:One use the same agents. It does not think or plan.
