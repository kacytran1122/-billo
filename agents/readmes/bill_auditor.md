# Billo Bill Auditor + Verifier

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Checks a medical bill line by line, live. Two checks vote on every possible problem: a **rules check** (duplicates, NCCI code pairs, $400 Good Faith Estimate rule) and a **price check** (real hospital price percentiles). Only problems both checks agree on go into the dispute letter. Part of Billo.

**Keywords:** medical bill audit, billing error, duplicate charge, NCCI, Good Faith Estimate, No Surprises Act, overcharge.
